# ProjectLink Web Application

A modern, dark-themed web application for student project collaboration.

## Features

- **Responsive Design**: Fully responsive design that works on desktop, tablet, and mobile devices
- **Dark Theme**: Sophisticated dark color scheme with smooth gradients and neon accents
- **Project Management**: Browse and filter projects based on age, skills, and roles
- **User Authentication**: Secure login and registration system
- **Application System**: Apply to projects and track application status
- **Contact Form**: Professional contact form with validation
- **Smooth Animations**: Fluid transitions and micro-interactions throughout
- **Modern UI**: Card-based layout with glassmorphism effects

## Technical Details

### HTML Structure
- Semantic HTML5 markup
- Accessible with proper ARIA labels
- Mobile-first approach

### CSS Styling
- CSS custom properties for theming
- Gradient backgrounds and effects
- Responsive grid layouts
- Media queries for mobile optimization

### JavaScript Functionality
- Project data management with sample projects
- Filter and search capabilities
- Modal windows for login/register
- Form validation
- Toast notifications
- Smooth scrolling navigation
- Intersection Observer for animations
- Local storage for project applications

### Design Inspiration
- **Color Palette**: Sophisticated high-contrast tech gradient scheme
- **Typography**: Inter font family for modern typography
- **Components**: Card-based UI with glassmorphism effects
- **Interactions**: Smooth hover states and transitions

## Pages

1. **Home Page**: Hero section with featured statistics and call-to-action buttons
2. **Projects Page**: Project listing with filtering and search capabilities
3. **How It Works**: Step-by-step process explanation
4. **About**: Project information and features overview
5. **Contact**: Contact form and company information

## Files

- `index.html` - Main application page
- `css/style.css` - Main stylesheet
- `js/app.js` - JavaScript functionality
- `test.html` - Test page for development
- `images/` - Placeholder images (SVGs recommended)

## Usage

1. Open `index.html` in a modern web browser
2. Test the filtering functionality on the Projects page
3. Try the login/register modal windows
4. Submit the contact form to test validation
5. Check responsive behavior on different screen sizes
